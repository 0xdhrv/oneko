## Design Context

### Users

This project is a React component and browser playground. Visitors try a cursor-following cat, choose its appearance and behavior, and can install it on their own website.

### Brand Personality

Small, playful, welcoming. The user's instructions require cat-themed copy and crisp, unchanged pixel art.

### Aesthetic Direction

The user wants a simple, user-friendly landing page with every feature retained. Preserve the existing light/dark theme tokens and pixel typography. Keep the cat central. The landing view must start with all skin and setting options closed; reveal them only when requested.

### Design Principles

- Make trying the cat immediate; no setup or onboarding is required.
- Keep one customization entry point visible; lazy-load skin choices and controls only after it is opened.
- Preserve every setting; simplification should reduce visual clutter.
- Use readable labels, familiar units, native keyboard controls, and mobile-sized targets.
- Preserve pixel art and reduced-motion behavior in both themes.
